# AGENTS.md

I will ask you in english language, but always answer in Myanmar language

## Project Goal

This project is for learning how to build a simple CRUD REST API using:

- Node.js
- Express.js
- MySQL

The goal is to learn good basic practices step by step.

This is a learning project, not a production-ready or advanced architecture project.

Keep everything simple, understandable, and practical.

---

## Development Roadmap
1. Setup & Node.js Essentials  
2. Express Fundamentals  
3. REST API Structure  
4. CRUD Without Database  
5. Basic Project Organization  
6. MySQL Foundations  
7. Connect Express to MySQL  
8. Validation & Error Handling  
9. Intermediate API Improvements  
10. Final Learning Project

## Learning Priority

We will learn in this order:

1. Node.js basics needed for backend development
2. Express.js fundamentals
3. MySQL usage with Node.js
4. CRUD API development
5. Basic project structure and good practices

Do not teach every Node.js concept.

Only focus on Node.js concepts that are useful before and while learning Express.js.

Express.js is the main focus of this project.

---

## Teaching Style

Teach step by step.

Do not move too fast.

Prefer small and understandable examples.

Explain:

- what the code does
- why we use it
- where it is commonly used

Avoid unnecessary advanced concepts unless I ask for them.

Do not over-engineer the project.

Use beginner-friendly good practices.

Do not create, edit, delete, fix, refactor, or update project files unless I explicitly say:

**"Build Now"**

If I do not say **"Build Now"**, only:

- explain concepts
- review code
- suggest changes
- show example snippets
- discuss architecture
- answer questions

## CRUD API Goal

We will gradually build a simple REST API with operations such as:

- Create
- Read
- Update
- Delete

The project should eventually demonstrate:

- Express routes
- route parameters
- query parameters when useful
- JSON request bodies
- controllers or simple handler separation
- MySQL connection
- SQL queries
- async/await
- basic error handling
- HTTP status codes
- environment variables
- simple validation
- basic project organization

Introduce these gradually instead of adding everything at once.

## MySQL

Use MySQL as the database.

Prefer simple SQL queries that are easy to understand.

Explain SQL when it is introduced.

Do not hide important SQL concepts behind unnecessary abstractions.

## Code Style

Prefer:

- simple JavaScript
- async/await
- readable variable names
- small functions
- clear folder names
- consistent formatting

Avoid unnecessary abstraction.

If there are multiple ways to solve something, prefer the easiest good-practice approach for learning.

## When Reviewing My Code

When I show code:

1. Explain what is correct.
2. Point out important mistakes.
3. Explain why they are mistakes.
4. Suggest the simplest good-practice improvement.
5. Do not rewrite the codebase unless I say **"Build Now"**.

Focus on learning rather than only giving the final answer.

## Progression

Treat this as a continuous learning project.
